# Mission 1 - Computer basics

## 1. Task / objective

Trace one activity through input, processing, output and storage. Identify hardware, software and three everyday computer systems.

## 2. Work completed

### IPOS activity

I chose writing and saving code in VS Code.

| Stage | What happened | Hardware or component |
| --- | --- | --- |
| Input | I type code and use the trackpad to click in the editor or save the file. | Keyboard and trackpad |
| Processing | The CPU runs VS Code's instructions, and memory holds the code while the file is open. | CPU and memory |
| Output | I can see the code and the save result on the screen. | Screen |
| Storage | When I save, the code file is stored on the computer. | SSD |

## 4. My understanding

When I type on the keyboard or click with the trackpad, that is input. The computer processes it while VS Code is open, and I see the code on the screen as output. When I save the file, it gets stored on the SSD. I can distinguish hardware from software because hardware is the physical part I can touch, while software is the program I use on it.
